# النسخة المصدرية 48 — الخاء والاختبار المرحلي

هذه نسخة مصدرية فقط. بناء APK وIPA مؤجل تنفيذًا لطلب المستخدم.

## حرف الخاء

- درس كامل لحرف خَ بنفس تسلسل الدروس السابقة، ومثاله المعتمد «خَرُوف».
- مراجعة قبلية تراكمية للأحرف الستة السابقة، في الحروف ثم الكلمات.
- نطق التعليق الصوتي هو «الخَا» لا اسم الحرف، ولا يذكر الشرح كلمة «فتحة».
- قالب كتابة مستقل: جسم الحاء، نقطة واحدة في الأعلى، ثم الحركة المعتمدة.
- 16 تعليقًا جديدًا للحرف بصوت Laloosh ونموذج Eleven v3.

## الاختبار المرحلي للمجموعة الأولى

- 16 نشاطًا تغطي أَ، بَ، تَ، ثَ، جَ، حَ، خَ.
- ثمانية أنماط: التعرّف، الصورة/الكلمة، التوصيل، الاستماع، النطق، الدليل، الكتابة الحرة، والتمييز البصري.
- واجهة موحدة خفيفة الحركة مع شريط تقدم وأرقام واضحة.
- تغيير مواقع البدائل والصور بين المحاولات لمنع حفظ الموضع.
- تصحيح فوري: الأحمر مع تعليق الخطأ، والأخضر مع تعليق النجاح والتشجيع والتصفيق.
- تدريب ذكي يعيد الحرف الضعيف في نشاطي صوت الحرف والكلمة، ولا يفتح المجموعة التالية قبل الإتقان.

## التحقق المنجز

- تحقق بنية حزم المحتوى وترابط الأصول: ناجح.
- تحقق ربط التعليقات الصوتية بالحروف: ناجح لسبعة دروس.
- تحقق وجود الصوتيات والصور والبصمات والمدد: ناجح.
- تحليل نحوي بديل: ناجح لكل ملفات Dart البالغ عددها 104.
- تشغيل Flutter واختبارات الواجهات المحلية تعذر بسبب سياسة Windows Device Guard التي حجبت `dart.exe`؛ لم يُنشأ أي ملف APK أو IPA.
