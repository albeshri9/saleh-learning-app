# Saleh v57

- صُححت أسئلة الحروف من الدال إلى السين لتستخدم أل التعريف مع التشكيل المعتمد: الدَّا، الذَّا، الرَّا، الزَّا، السَّا.
- أُعيد توليد تسجيلي سؤال الحرف وسؤال الصورة لكل حرف بصوت Laloosh ونموذج Eleven v3، مع فاصل 1.5 ثانية بين الطلبات.
- حُدثت المراجعات القبلية التي تعيد استخدام التسجيلات نفسها، وتأكد تطابق أحجام الملفات وبصمات SHA-256 مع سجل الصوتيات.
- اعتُمدت النقرة الخشبية الناعمة التي اختارها المستخدم كصوت نقر واحد قصير ومتزامن مع نبضة اللمس.
- بقي الوصول المباشر والتخطي الشامل مفعّلين في هذه النسخة التجريبية كما في v56.
